PLANET SIX STUDIO V8 — 정리 버전

수정 내용
- 이전 버전의 겹쳐 보이던 모든 첫 화면 글자와 오래된 레이어 제거
- 첫 화면에 브랜드 패널을 하나만 사용
- STUDIO 자간과 크기를 정돈

- 왼쪽은 밝은 글라스 패널과 도시가 자연스럽게 이어지도록 구성
- 버튼을 한 줄로 정리
- 아래 소개, 작품, 서비스, 작업 과정, 문의 섹션 유지
- 모바일 메뉴와 스크롤 정상 작동

업로드 방법
1. 압축을 풉니다.

3. 모든 파일과 assets 폴더를 기존 파일 위에 업로드

PLANET SIX STUDIO V11

주요 수정
- 업로드한 원본 로고에서 빨간 정사각형 6자 심볼을 직접 추출해 그대로 사용
- 로고의 검은 부분은 투명 처리하여 뒤 배경이 드러나도록 제작
- 왼쪽 위 로고를 이미지 생성으로 다시 그리지 않고 실제 원본 에셋으로 적용
- 메인 카피를 '상상을, 새로운 영상으로.'로 정리
- 영상 제작 문의 버튼은 짙은 네이비 입체 하이그로시 버튼
- 작품 보기 버튼은 포토샵 스타일의 실버 유광 입체 버튼
- 검은 브랜드 패널 크기를 줄이고 위쪽으로 이동
- 오리지널 자동차를 전면에 유지
- 기존 겹침을 막기 위해 첫 화면 HTML/CSS를 새로 작성
- 모바일과 스크롤 기능 유지

업로드
1. 압축을 풉니다.
2. GitHub 저장소에서 Add file → Upload files
3. 모든 파일과 assets 폴더를 기존 파일 위에 업로드
4. Commit changes
5. 1~3분 후 Ctrl+F5

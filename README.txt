변경 내용
- 사용자가 최종 확정한 메인 화면을 홈페이지 Hero로 적용
- 화면 전체가 하나로 이어지므로 기존의 양분 현상 제거
- 메인 화면의 ABOUT / WORKS / SERVICES / PROCESS / CONTACT 클릭 가능
- 영상 제작 문의하기 / 작품 보기 / SCROLL 클릭 가능
- 기존 ABOUT, WORKS, SERVICES, PROCESS, CONTACT 하단 섹션 유지

GitHub 업로드
1. ZIP 압축을 풉니다.
2. GitHub의 planetsix 저장소로 이동합니다.
3. Add file → Upload files
4. 압축을 푼 파일 전체와 assets 폴더를 업로드합니다.
5. Commit changes
6. 1~3분 뒤 홈페이지에서 Ctrl+F5

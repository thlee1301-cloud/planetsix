PLANET SIX STUDIO V9

수정 내용
- 검은 브랜드 패널을 화면 중앙으로 이동
- STUDIO 글자를 더 크게 하고 자간 확대
- 메인 카피에 Space Grotesk 기반의 세련된 디스플레이 스타일 적용
- '상상을 영상으로. 영상을 만들어보세요.'를 보다 감각적으로 정리
- 설명 문장을 한 줄 흐름으로 구성
- 영상 제작 문의 / 작품 보기 버튼을 포토샵 아이콘처럼 입체형 하이그로시 버튼으로 제작
- 왼쪽은 가까운 오브젝트 없이 미래도시 건물 원경 중심의 배경으로 변경
- 오리지널 자동차는 오른쪽 전면에 유지
- 모바일 반응형 및 스크롤 기능 유지

업로드 방법
1. 압축을 풉니다.
2. GitHub 저장소에서 Add file → Upload files
3. 모든 파일과 assets 폴더를 기존 파일 위에 업로드
4. Commit changes
5. 1~3분 후 Ctrl+F5

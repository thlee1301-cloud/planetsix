PLANET SIX STUDIO 홈페이지 V5 — 미래도시 테스트 버전

이번 수정
- 확정한 미래도시 이미지를 실제 홈페이지 첫 화면 배경으로 적용
- 메인 자동차를 전면 우측에 유지
- 곡선형 미래도로, 미래도시, 드론을 함께 노출
- 중앙 입체형 PLANET·SIX 패널 적용
- 기존 첫 화면 글자 중복 제거
- 아래쪽 기존 회사 소개/작품/서비스 섹션과 스크롤 기능 유지

업로드 방법
1. 압축을 풉니다.
2. GitHub planetsix 저장소에서 Add file → Upload files를 누릅니다.
3. 압축 안의 파일과 assets 폴더를 모두 기존 파일 위에 업로드합니다.
4. Commit changes를 누릅니다.
5. 약 1~3분 후 홈페이지에서 Ctrl+F5를 누릅니다.

참고
- 첫 화면 이미지 안에 메뉴 글자가 포함되어 있어, 실제 클릭 영역을 같은 위치에 투명하게 두었습니다.
- 테스트 후 최종판에서는 이미지 속 글자와 메뉴를 분리해 더 정교한 반응형 홈페이지로 발전시키는 것이 좋습니다.

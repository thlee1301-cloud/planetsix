PLANET SIX STUDIO V10 — 최종 정리 방향

핵심 수정
- 첫 화면에 단 하나의 미래도시 배경만 사용하여 겹침 제거
- 검은 브랜드 패널을 중앙 상단에 배치
- STUDIO 글자를 더 크게 하고 자간 확대
- AI 영상 제작 스튜디오 → 메인 카피 → 설명 → 버튼 순서로 정리
- 오리지널 자동차를 우측 전면에 유지
- 배경 드론과 건물은 원경으로 통일
- 버튼은 입체적인 하이그로시 형태로 정돈
- 좌측 상단 로고를 더 크게 표시
- 기존에 겹쳐 보이던 오래된 스타일과 레이어를 완전히 제거
- 모바일 메뉴와 스크롤 유지

업로드 방법
1. 압축을 풉니다.
2. GitHub 저장소에서 Add file → Upload files
3. 모든 파일과 assets 폴더를 기존 파일 위에 업로드
4. Commit changes
5. 1~3분 후 Ctrl+F5

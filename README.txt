PLANET SIX STUDIO 홈페이지 V4 안정화 버전

수정 내용
- 스크롤을 막던 영화형 오프닝을 완전히 제거
- 화면이 좌우로 갈라져 보이던 배경 설정 수정
- 메인 이미지를 화면 전체에 자연스럽게 채움
- PLANET SIX의 감각적인 타이포그래피는 유지
- 스크롤 시 상단 메뉴가 작아지는 효과는 안정적으로 유지

업로드 방법
1. 압축을 풉니다.
2. GitHub 저장소에서 Add file → Upload files를 누릅니다.
3. 압축 안의 모든 파일과 assets 폴더를 기존 파일 위에 업로드합니다.
4. Commit changes를 누릅니다.
5. 1~3분 후 홈페이지에서 Ctrl+F5를 누릅니다.

PLANET SIX STUDIO V13 — 안정화 버전

핵심 변경
- 미래도시와 자동차를 하나의 완성된 히어로 이미지로 통합
- 자동차 이미지, 도시 배경, 검은 박스가 중복되는 구조 완전 제거
- 화면이 좌우로 갈라지는 문제 제거
- 왼쪽 위에는 업로드한 원본 6 로고를 실제 HTML 요소로 적용
- 기존 이미지 속 로고 영역은 하늘색으로 정리
- 메뉴는 이미지 위치에 맞춘 클릭 영역으로 제공
- 영상 제작 문의 버튼은 네이비 입체 하이그로시
- 작품 보기 버튼은 실버·크롬 입체 버튼으로 덮어 표시
- 아래 소개·작품·서비스·진행 과정·문의 섹션 유지
- 데스크톱 16:9 화면에서 가장 안정적으로 보이도록 구성

업로드 방법
1. 압축을 풉니다.
2. GitHub 저장소에서 Add file → Upload files
3. 모든 파일과 assets 폴더를 기존 파일 위에 업로드
4. Commit changes
5. 1~3분 후 Ctrl+F5

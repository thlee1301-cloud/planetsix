# PLANET SIX 최종 정리본

이 버전은 투명 버튼이 배경 이미지와 같은 비율로 함께 움직이도록 다시 만들었습니다.
따라서 화면 크기가 달라져도 클릭 영역이 버튼 위에서 어긋나지 않습니다.

## GitHub에 올리는 방법

1. 이 ZIP의 압축을 풉니다.
2. 안에 있는 `index.html`, `styles.css`, `assets` 폴더를 선택합니다.
3. GitHub 저장소 첫 화면에 바로 업로드합니다.
4. 기존 파일 교체를 승인하고 `Commit changes`를 누릅니다.
5. 1~2분 뒤 홈페이지에서 `Ctrl + F5`를 누릅니다.

중요: ZIP 자체나 `PLANET_SIX_CLEAN_FINAL` 폴더를 저장소 안에 올리지 마세요. 안의 세 항목이 저장소 첫 화면에 보여야 합니다.
